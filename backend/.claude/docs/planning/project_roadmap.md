## 📋 项目概述

Zeebee 是一个基于 Go 语言的微服务贷款管理系统，采用 go-zero 框架构建。项目旨在提供完整的贷款生命周期管理，包括借款方管理、贷款方审核和预审批等功能。

## 🎯 项目目标

### 业务目标

- 提供端到端的贷款管理解决方案
- 支持多角色协作（借款方、贷款方、管理员）
- 实现自动化的预审批和风险评估
- 确保数据安全和合规性

### 技术目标

- 构建可扩展的微服务架构
- 实现高可用性和高性能
- 建立完善的监控和日志系统
- 达到 80%+ 的测试覆盖率

## 🔧 技术栈选择

### 核心技术

- **后端框架**: go-zero v1.9.3
- **数据库**: PostgreSQL 14+ + Redis 7+
- **消息队列**: NATS/JetStream (计划)
- **文件存储**: AWS S3
- **容器化**: Docker + Kubernetes

### 监控和运维

- **日志**: ELK Stack (计划)
- **监控**: Prometheus + Grafana (计划)
- **链路追踪**: Jaeger (计划)
- **CI/CD**: GitHub Actions (计划)

## 🚀 发布计划

### 版本策略

- **主版本**: 每年 1-2 次，包含重大架构变更
- **次版本**: 每季度 1 次，包含新功能和改进
- **补丁版本**: 每月 1-2 次，包含 bug 修复

### 发布流程

1. **开发分支** → 功能开发和测试
2. **测试分支** → 集成测试和质量检查
3. **预发布** → 生产环境验证
4. **生产发布** → 正式部署

### 环境管理

- **开发环境**: 持续集成，自动部署
- **测试环境**: 每日构建，手动部署
- **预发布环境**: 版本发布前验证
- **生产环境**: 严格流程，计划内发布
