## README 文档规范

### 写作规范

1. **结构清晰**: 使用标准 Markdown 格式
2. **内容完整**: 包含必要的使用信息
3. **示例丰富**: 提供实际的代码示例
4. **保持更新**: 随项目变更及时更新

